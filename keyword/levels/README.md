# Совместимость старого адреса Keyword

Основной каталог и новые публикации находятся в отдельном репозитории:
https://github.com/ThemeCross/Keyword-levels

Адрес актуального источника приложения:
https://themecross.github.io/Keyword-levels/catalog-ru.json

Этот каталог содержит неизменяемую копию generation 1 только для сборок,
которые ещё обращаются к прежнему /keyword/levels/catalog-ru.json.
Здесь не добавляются новые поколения и не редактируются старые JSON.
Словарь, ID, SHA и содержимое исходной поставки сохранены.

Удаление старого адреса отложено до согласованного перехода установленных
сборок. Изменения контента публикуются только в ThemeCross/Keyword-levels.
